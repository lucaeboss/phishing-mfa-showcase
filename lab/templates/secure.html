Passkey (FIDO2 / WebAuthn)

First enroll a password account at /enroll, then add a passkey to it here. Uses Windows Hello / a security key / your phone.

Why this breaks the attack

  • Nothing to phish. There is no password or code to type into the evil portal.
  • Origin-bound. The browser signs a challenge tied to localhost. A fake page on another origin cannot get a signature the server will accept — so an AiTM relay can’t forward it either.
  • Private key never leaves the authenticator. There is no shared secret sitting on the server to steal.

Try it: register a passkey here, then open the evil portal — notice it has no way to capture a passkey at all.
